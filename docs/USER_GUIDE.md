# 사용 설명서

## 1. 설치

1. `GoniPdfPrinterSetup-1.0.0.exe`를 실행합니다.
2. 사용자 계정 컨트롤(UAC) 창에서 **예**를 누릅니다.
3. 설치 폴더를 확인하고 **설치**를 누릅니다.
4. 완료 화면에서 "Goni PDF 트레이 앱 실행"을 체크한 채 **마침**을 누릅니다.

설치가 끝나면 프린터 목록에 **Goni PDF**가 추가되고, 작업 표시줄 알림 영역에 PDF 아이콘이 나타납니다.
다음 로그온부터는 앱이 자동으로 실행됩니다.

## 2. 사용 방법

1. 워드, 엑셀, 한글, 브라우저 등 아무 프로그램에서 **인쇄**를 선택합니다.
2. 프린터로 **Goni PDF**를 고르고 인쇄합니다.
3. 보안 설정 창이 뜨면 원하는 옵션을 지정하고 **저장**을 누릅니다.

### 설정 창 항목

**암호 열기**
- *문서를 열 때 암호를 요구합니다* — 체크하면 PDF를 열 때 암호를 물어봅니다.

**권한**
- *문서 보안 설정 변경이나 특정 기능 사용 시 암호를 요구합니다* — 체크하면 아래 제한이 적용되고, 권한 암호를 아는 사람만 제한을 풀 수 있습니다.
- *인쇄 허용 범위* — 없음 / 저해상도(150 dpi) / 고해상도
- *편집 허용 범위* — 없음 / 페이지 삽입, 삭제 및 회전 / 양식 필드 채우기 및 서명 / 주석 작성, 양식 필드 채우기 및 서명 / 페이지 추출을 제외한 모든 작업
- *문구, 이미지를 포함한 내용물의 복사를 허용합니다*
- *화면 판독기 등 접근성 도구의 텍스트 접근을 허용합니다*

> 열기 암호와 권한 암호는 서로 달라야 합니다.

**기타 옵션**
- *암호화 방식* — AES-256(권장, 한글 암호 가능) / AES-128(오래된 뷰어 호환, 영문·숫자·기호 암호만)
- *메타데이터도 암호화* — 제목·작성자 등 문서 정보까지 암호화
- *암호를 기억합니다* — 다음 인쇄 때 암호가 자동으로 채워집니다. Windows 계정으로 보호되어 저장됩니다.
- *저장 후 PDF 파일을 엽니다*
- *다음부터 이 창 없이 마지막 설정으로 바로 저장합니다* — 창을 띄우지 않고 저장 폴더에 바로 저장합니다(같은 이름이 있으면 `이름 (2).pdf`).

**저장 위치**
- 폴더와 파일 이름. 파일 이름은 인쇄한 문서 제목으로 자동 입력됩니다.

모든 설정은 저장할 때 기억되어 다음 인쇄 때 그대로 표시됩니다.

## 3. 트레이 메뉴

알림 영역의 PDF 아이콘을 오른쪽 클릭합니다.

| 메뉴 | 기능 |
|---|---|
| 기본 보안 설정... | 다음 인쇄에 쓸 기본값 변경 (아이콘 더블클릭과 동일) |
| 저장 폴더 열기 | 마지막 저장 폴더를 탐색기로 열기 |
| 종료 | 트레이 앱 종료 (종료 중에는 인쇄가 처리되지 않음) |

저장 완료 알림을 클릭하면 저장된 파일이 선택된 상태로 탐색기가 열립니다.

## 4. 문제 해결

| 증상 | 해결 |
|---|---|
| 인쇄해도 아무 일이 없고 인쇄 대기열에 "오류" 표시 | 트레이 앱이 꺼져 있습니다. 시작 메뉴 → Goni PDF → *Goni PDF 트레이 앱* 실행 후 대기열에서 작업을 *다시 시작* |
| "창 없이 바로 저장"을 끄고 싶음 | 트레이 아이콘 더블클릭 → 해당 항목 체크 해제 → 확인 |
| "PDF가 아닌 인쇄 데이터" 알림 | 프린터 속성에서 드라이버가 *Microsoft Print To PDF*인지 확인, 설치 프로그램 재실행 |
| AES-128에서 한글 암호 오류 | AES-128은 영문/숫자/기호만 지원합니다. AES-256을 선택하세요 |
| 권한 제한이 적용되지 않는 것 같음 | 일부 뷰어는 권한 플래그를 무시합니다. Adobe Acrobat/Reader, Edge, Chrome에서 확인하세요 |

## 5. 제거

**설정 → 앱 → 설치된 앱**에서 *Goni PDF 가상 프린터*를 제거하거나, 시작 메뉴 → Goni PDF → *Goni PDF 제거*를 실행합니다.
프린터와 포트도 함께 제거되며, 사용자 설정(`%APPDATA%\GoniPdfPrinter`)은 남습니다.
