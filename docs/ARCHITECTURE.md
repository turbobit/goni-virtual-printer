# 설계 문서

## 1. 목표

- 모든 Windows 프로그램에서 사용할 수 있는 **가상 프린터**로 동작한다.
- 인쇄 결과를 PDF로 저장하면서 **열기 암호, 권한 암호, 인쇄·편집·복사 권한**을 지정한다.
- 마지막으로 사용한 설정을 기억한다.
- 외부 라이브러리나 별도 드라이버 없이, Windows 기본 구성요소만으로 빌드·실행한다.

## 2. 전체 구조

```
┌────────────────┐   GDI/XPS    ┌──────────────────────────────┐
│ 아무 응용 프로그램 │ ───────────▶ │ 인쇄 스풀러 (spoolsv.exe)       │
└────────────────┘   인쇄        │  프린터: "Goni PDF"            │
                                 │  드라이버: Microsoft Print To PDF│ ← Windows 내장 v4 드라이버
                                 │  포트: \\.\pipe\GoniPdfPrinter │ ← 로컬 포트(Local Port)
                                 └──────────────┬───────────────┘
                                                │ PDF 바이트 스트림 (작업 1건 = 연결 1건)
                                                ▼
                                 ┌──────────────────────────────┐
                                 │ GoniPdfPrinter.exe (트레이)    │
                                 │  PipeListener → 작업 큐        │
                                 │  SecurityForm (설정 창)        │
                                 │  PdfEncryptor (AES 암호화)     │
                                 └──────────────┬───────────────┘
                                                ▼
                                        암호화된 PDF 파일
```

### 왜 이 구조인가

| 대안 | 채택하지 않은 이유 |
|---|---|
| 자체 프린터 드라이버(v3/v4) 개발 | WDK, 드라이버 서명이 필요하고 배포가 어렵다 |
| Ghostscript + 포트 모니터(RedMon 등) | 외부 바이너리 설치·라이선스(AGPL) 부담 |
| 로컬 포트를 파일 경로로 지정 | 고정 파일명이라 동시 작업 충돌, 폴링 필요 |
| **내장 PDF 드라이버 + 명명된 파이프 포트** | 드라이버 설치 없음, 작업 경계(연결 종료)가 명확, 즉시 수신 |

스풀러의 로컬 포트 모니터는 포트 이름을 `CreateFile`로 열어 데이터를 쓴다. 포트 이름을
`\\.\pipe\GoniPdfPrinter`로 지정하면 트레이 앱이 연 파이프 서버로 PDF가 그대로 전달된다.

## 3. 구성 요소

| 파일 | 역할 |
|---|---|
| `src/Program.cs` | 진입점(명령줄 분기), 단일 인스턴스 뮤텍스, `TrayApp`, `PipeListener`, 아이콘 |
| `src/SecurityForm.cs` | 보안 설정 창(작업 모드/설정 모드), 파일명 생성 `FileNames` |
| `src/AppSettings.cs` | `settings.ini` 읽기·쓰기, DPAPI 암호 보호 |
| `src/PdfModel.cs` | PDF 객체 모델, 렉서/파서, 교차참조 해석, 손상 파일 복구 |
| `src/PdfSecurity.cs` | 권한 옵션, `/P` 계산, AES-256(R6)·AES-128(R4) 처리기, 암호화 PDF 작성기 |
| `installer/GoniPdfPrinter.nsi` | NSIS 설치 프로그램 정의 |
| `installer/printer.ps1` | 프린터·포트 등록/제거 (설치 프로그램이 호출) |
| `build.ps1` | 컴파일(.NET Framework `csc.exe`), 아이콘 생성, 설치 프로그램 빌드 |
| `install.ps1`, `uninstall.ps1` | 개발용 설치/제거 스크립트 |

## 4. 인쇄 작업 처리 흐름

1. `PipeListener`가 파이프 서버 인스턴스를 만들고 `WaitForConnection`으로 대기한다.
   연결되면 즉시 다음 인스턴스를 만들어 동시 작업을 받을 수 있게 하고, 수신은 스레드 풀에서 처리한다.
2. 스풀러가 핸들을 닫으면(EOF) 수신한 바이트 전체를 하나의 작업으로 UI 스레드 큐에 넣는다.
3. `TrayApp.ProcessJob`
   - `%PDF` 헤더 확인 (다른 드라이버가 연결된 경우 오류 알림)
   - PDF `/Info /Title`(= 인쇄한 문서 이름)로 기본 파일명 생성 (`보고서.docx` → `보고서`)
   - 설정 로드 → "창 없이 저장"이 꺼져 있거나 설정이 불완전하면 `SecurityForm` 표시
   - `PdfEncryptor.Encrypt` → 파일 저장 → 설정 저장 → 알림 / 저장 후 열기
   - 오류 시 메시지 후 설정 창으로 돌아가 재시도
4. 작업은 큐로 직렬 처리되어 설정 창이 중첩되지 않는다.

### 파이프 보안

파이프 DACL은 `LocalSystem`(스풀러), `Administrators`, 현재 사용자에게만 접근을 허용한다.

## 5. PDF 암호화 구현

### 5.1 파싱

- `startxref`에서 시작해 교차참조 **테이블**과 **스트림**(`/Type /XRef`, PNG predictor 포함)을 `/Prev`, `/XRefStm` 체인까지 따라간다.
- 압축 객체(**객체 스트림**, `/Type /ObjStm`)는 Flate 해제 후 개별 객체로 펼친다.
- 교차참조가 손상되면 `n g obj` 패턴을 스캔해 재구성한다.
- 스트림 길이는 `/Length`(간접 참조 포함)를 사용하고, 맞지 않으면 `endstream` 검색으로 보정한다.

### 5.2 재작성

- 모든 살아 있는 객체를 같은 번호·세대로 다시 쓴다. XRef/ObjStm 스트림은 제외(내용은 일반 객체로 기록).
- 모든 **문자열**과 **스트림**을 객체별로 암호화하고 문자열은 16진 표기로 쓴다. `/Length`는 새 길이로 갱신한다.
- `/EncryptMetadata false`이면 `/Type /Metadata` 스트림은 암호화하지 않는다.
- 새 `/Encrypt` 사전 객체를 추가하고, 고전 교차참조 테이블과 트레일러(`/ID` 포함)를 작성한다.
- AES-256이고 원본 버전이 2.0 미만이면 카탈로그에 `/Extensions /ADBE (ExtensionLevel 8)`를 추가한다.

### 5.3 보안 처리기

| 방식 | 사전 | 키 | 비고 |
|---|---|---|---|
| AES-256 | `/V 5 /R 6`, `/CFM /AESV3` | 무작위 32바이트 파일 키 | ISO 32000-2 알고리즘 2.B(SHA-256/384/512 반복), `U/UE/O/OE/Perms`. 암호는 NFKC 정규화 후 UTF-8 → 한글 가능 |
| AES-128 | `/V 4 /R 4`, `/CFM /AESV2` | 알고리즘 2 (MD5 50회) | 객체 키 = MD5(키 + 객체번호 + 세대 + `sAlT`). 암호는 Latin-1 → 영문/숫자/기호만 |

공통: AES-CBC, 무작위 IV 16바이트를 앞에 붙이고 PKCS#7 패딩.

열기 암호만 있고 권한 제한이 없으면 소유자 암호 = 사용자 암호, `/P = -4`(전체 허용).

### 5.4 권한 비트 (`/P`, ISO 32000 표 22)

| UI 항목 | 값 | 설정 비트 |
|---|---|---|
| 인쇄 | 저해상도 | 3 |
| | 고해상도 | 3, 12 |
| 편집 | 페이지 삽입, 삭제 및 회전 | 11 |
| | 양식 필드 채우기 및 서명 | 9 |
| | 주석 작성, 양식 필드 채우기 및 서명 | 6, 9 |
| | 페이지 추출을 제외한 모든 작업 | 4, 6, 9, 11 |
| 복사 허용 | | 5 |
| 접근성 텍스트 접근 | | 10 |

비트 7·8, 13~32는 항상 1, 비트 1·2는 0.

## 6. 설정 저장

- 위치: `%APPDATA%\GoniPdfPrinter\settings.ini` (UTF-8, `키=값`)
- 저장 시점: 작업 저장 성공 시, 설정 창 [확인] 시
- 암호: "암호 기억"이 켜져 있을 때만, `ProtectedData.Protect`(DPAPI, CurrentUser 범위, 고유 엔트로피)로 암호화한 Base64로 저장. 다른 사용자/PC에서는 복호화할 수 없다.
- 임시 파일에 쓴 뒤 교체하여 손상을 방지한다.

## 7. 설치 구성

| 항목 | 값 |
|---|---|
| 설치 폴더 | `C:\Program Files\GoniPdfPrinter` |
| 프린터 / 포트 | `Goni PDF` / `\\.\pipe\GoniPdfPrinter` |
| 자동 실행 | `HKLM\Software\Microsoft\Windows\CurrentVersion\Run\GoniPdfPrinter` |
| 제거 정보 | `HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall\GoniPdfPrinter` |
| 시작 메뉴 | `Goni PDF` 폴더 (트레이 앱, 기본 보안 설정, 제거) |

설치 프로그램은 관리자 권한으로 실행되므로, 트레이 앱은 `explorer.exe`를 통해 현재 사용자 권한으로 시작한다
(파이프 DACL과 설정 경로가 사용자 기준이어야 하기 때문).

## 8. 알려진 제한

- 트레이 앱이 실행 중이 아니면 포트를 열 수 없어 인쇄 작업이 "오류" 상태로 남는다. 앱 실행 후 작업을 다시 시작하면 된다.
- 한 PC에서 여러 사용자가 동시에 로그온하면 파이프 이름이 같아 먼저 실행한 사용자만 수신한다.
- 권한 제한은 PDF 표준 규약이므로 이를 무시하는 도구로는 우회될 수 있다. (열기 암호는 AES로 실제 보호됨)
- 지원 필터는 교차참조/객체 스트림의 `FlateDecode`뿐이다. 일반 콘텐츠 스트림은 필터와 무관하게 그대로 암호화된다.
- Windows 보호된 인쇄 모드(WPP)에서는 사용자 지정 포트 프린터가 제한될 수 있다.
